# MASAC: Abstract-Then-Concretize Automated Multi-Agent System Design

## Project context

MASAC is a public research system for automatically designing query-specific LLM multi-agent workflows. It first abstracts reusable components from existing workflows, then selects and concretizes them for a new query.

## Contributor scope

- Coauthored the public MASAC paper.
- Contributed to system implementation, experimental design, and evaluation.
- Worked with workflows represented through operators plus control and data flows.

## Technical evidence

- Reused design abstractions rather than constructing every multi-agent workflow from scratch.
- Generated executable workflows tailored to new coding and reasoning inputs.
- Evaluated the method against stated baselines on supported benchmarks.

## Result boundaries

The public paper reports system-level improvements of up to 200% in accuracy, up to 20% lower generation time, and 32% lower computational cost. These are MASAC results and must never be presented as an individual contributor's personal metrics.
