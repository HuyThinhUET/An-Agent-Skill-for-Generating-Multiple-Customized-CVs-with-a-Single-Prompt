# MABe Mouse Behavior Detection summary

Source: `input/projects-information/mabe-mouse-behavior-detection.md`

Role-neutral facts: A team built a pose-based mouse-behavior pipeline with temporal and interaction features, a LightGBM/XGBoost/CatBoost ensemble, cross-validation, adaptive thresholds, and temporal post-processing. The team placed 53rd of 1,413 public-leaderboard teams with 0.481 F-beta.

Relevant tags: machine learning, time series, feature engineering, gradient boosting, ensemble learning, cross-validation, data science, teamwork.
